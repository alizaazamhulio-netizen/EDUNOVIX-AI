MODULE 00

Introduction to Trigonometry

Trigonometry (from Greek trigōnon "triangle" and metron "measure") is the branch of mathematics that explores the precise quantitative relationships between the side lengths and angles of triangles, and generalizes these concepts into cyclic, periodic real functions.

While it begins with the geometry of right-angled triangles, trigonometry quickly expands to model wave mechanics, circular motion, vectors, alternating electrical currents, signal processing, astronomical distances, computer graphics rendering engines, and civil engineering structures.

⚡ FAST / NET / ECAT Admission Insight

Trigonometry forms roughly 15% to 22% of the Mathematics section in FAST-NUCES, NUST NET, and ECAT tests. The majority of entry-test questions test rapid algebraic simplification of identities, standard angle evaluations, and recognition of quadrant signs.

MODULE 01

Basic Trigonometric Vocabulary

Before computing ratios, every student must master the foundational geometrical definitions:

  • Angle (θ): The geometric figure formed by two rays sharing a common endpoint called the vertex.
  • Right Angle: An angle measuring exactly 90° (π/2 radians).
  • Acute Angle: An angle strictly less than 90° (0° < θ < 90°).
  • Obtuse Angle: An angle strictly between 90° and 180° (90° < θ < 180°).
  • Hypotenuse: The longest side of a right-angled triangle, always situated directly opposite to the 90° right angle.
  • Opposite Side: The side situated directly across from the specified acute reference angle θ.
  • Adjacent Side: The side situated adjacent (next to) the specified reference angle θ, forming one of the arms of θ alongside the hypotenuse.

MODULE 02

The Pythagorean Theorem

In any Euclidean right-angled triangle, the area of the square whose side is the hypotenuse is equal to the sum of the areas of the squares on the other two sides.

Pythagorean Theorem
a² + b² = c²  ⟺  c = √(a² + b²) a = √(c² - b²),   b = √(c² - a²)
⚡ Speed Triple Recognition for Entry Tests

Do not manually compute squares during tests! Memorize the fundamental Pythagorean Triples and their multiples:
• (3, 4, 5) → (6, 8, 10), (9, 12, 15), (30, 40, 50)
• (5, 12, 13) → (10, 24, 26), (15, 36, 39)
• (8, 15, 17)  |  (7, 24, 25)  |  (9, 40, 41)  |  (11, 60, 61)  |  (1, 1, √2)  |  (1, √3, 2)

Worked Example 2.1 FAST-Style

Find the length of the unknown leg in a right triangle having hypotenuse c = 25 and one leg a = 7.

1. Identify known values: a = 7, c = 25.
2. Apply formula: b = √(c² - a²) = √(25² - 7²) = √(625 - 49) = √576 = 24.
3. Shortcut recognition: (7, 24, 25) is a standard primitive triple.
Try Yourself 2.1

A rectangular plot of land has length 40 meters and width 9 meters. What is the length of the diagonal walkway running across the plot?

Solution: The diagonal forms the hypotenuse: d = √(40² + 9²) = √(1600 + 81) = √1681 = 41 meters. (Triple 9-40-41).
MODULE 03

Primary Trigonometric Ratios (SOH-CAH-TOA)

The three primary trigonometric ratios define the proportions between the sides of a right triangle with respect to an acute angle θ:

Primary Trigonometric Ratios
sin θ = Opposite / Hypotenuse cos θ = Adjacent / Hypotenuse tan θ = Opposite / Adjacent = sin θ / cos θ
VISUAL MEMORY AID: SOH — CAH — TOA
SOH → Sin = Opposite / Hypotenuse
CAH → Cos = Adjacent / Hypotenuse
TOA → Tan = Opposite / Adjacent
Worked Example 3.1 NET-Style

In a right-angled triangle with sides a = 5, b = 12, and c = 13, determine sin θ, cos θ, and tan θ where θ is the angle opposite to side a.

1. Opposite = 5, Adjacent = 12, Hypotenuse = 13.
2. sin θ = 5 / 13.
3. cos θ = 12 / 13.
4. tan θ = 5 / 12.
Try Yourself 3.1

If cos θ = 8/17 and θ is acute, find the exact value of tan θ.

Solution: Adjacent = 8, Hypotenuse = 17 → Opposite = √(17² - 8²) = 15. Thus tan θ = Opposite / Adjacent = 15/8.
MODULE 04

Reciprocal Trigonometric Functions

Each primary ratio has an exact reciprocal function:

Reciprocal Ratios
cosec θ (or csc θ) = 1 / sin θ = Hypotenuse / Opposite sec θ = 1 / cos θ = Hypotenuse / Adjacent cot θ = 1 / tan θ = Adjacent / Opposite = cos θ / sin θ
Worked Example 4.1 ECAT-Style

If sec θ = 5/3 and θ is acute, calculate cosec θ + cot θ.

1. sec θ = Hypotenuse / Adjacent = 5 / 3 → Hypotenuse = 5, Adjacent = 3.
2. Opposite = √(5² - 3²) = 4.
3. cosec θ = 5/4, cot θ = 3/4.
4. cosec θ + cot θ = 5/4 + 3/4 = 8/4 = 2.
MODULE 05

Pythagorean Trigonometric Identities

Dividing the Pythagorean equation a² + b² = c² by c², b², and a² respectively generates the three immortal Pythagorean identities:

The Three Pythagorean Identities
1. sin² θ + cos² θ = 1  ⟺  sin² θ = 1 - cos² θ  ⟺  cos² θ = 1 - sin² θ 2. 1 + tan² θ = sec² θ  ⟺  sec² θ - tan² θ = 1  ⟺  tan² θ = sec² θ - 1 3. 1 + cot² θ = cosec² θ  ⟺  cosec² θ - cot² θ = 1  ⟺  cot² θ = cosec² θ - 1
⚡ Algebraic Factorization Shortcut (High-Yield Entry Test Trick)

Because sec² θ - tan² θ = 1 is a difference of two squares, we have:
(sec θ + tan θ)(sec θ - tan θ) = 1  ⟹  sec θ - tan θ = 1 / (sec θ + tan θ)
Likewise: (cosec θ + cot θ)(cosec θ - cot θ) = 1  ⟹  cosec θ - cot θ = 1 / (cosec θ + cot θ).

Worked Example 5.1 FAST-Style

If sec θ + tan θ = 4, find the value of sin θ.

1. sec θ + tan θ = 4.
2. By the reciprocal property, sec θ - tan θ = 1/4 = 0.25.
3. Adding the two equations: 2 sec θ = 4 + 0.25 = 4.25 → sec θ = 2.125 = 17/8.
4. Subtracting the equations: 2 tan θ = 4 - 0.25 = 3.75 → tan θ = 1.875 = 15/8.
5. sin θ = tan θ / sec θ = (15/8) / (17/8) = 15/17.

MODULE 07

The "Square Root over 2" Memory Rule

Never forget sine values again! Write the sequence 0, 1, 2, 3, 4 under square root and divide by 2:

Sine Root Sequence (0° → 90°)
sin 0° = √0 / 2 = 0 sin 30° = √1 / 2 = 1/2 sin 45° = √2 / 2 = 1/√2 sin 60° = √3 / 2 sin 90° = √4 / 2 = 2/2 = 1

For cosine, simply reverse the sequence (from √4/2 down to √0/2). For tangent, divide sine by cosine (√Numerator_sin / √Numerator_cos).

MODULE 10 & 11

Reference Angles & The 4-Step Quadrant Protocol

A Reference Angle (α) is the positive acute angle between the terminal ray and the x-axis (never the y-axis!).

Reference Angle Formulas
Quadrant I (0° to 90°): α = θ Quadrant II (90° to 180°): α = 180° - θ  (or π - θ) Quadrant III (180° to 270°): α = θ - 180°  (or θ - π) Quadrant IV (270° to 360°): α = 360° - θ  (or 2π - θ)
4-Step Protocol: Finding cos 240° Walkthrough
Step 1: Identify Quadrant: 240° lies in Quadrant III (180° < 240° < 270°).
Step 2: Find Reference Angle: α = 240° - 180° = 60°.
Step 3: Determine Sign by ASTC: In Q3, Cosine is negative (-).
Step 4: Compute Value: cos 240° = -cos 60° = -1/2.
MODULE 13

Allied Angles & Reduction Formulas

Allied angles are angles associated with θ in the form (n × 90° ± θ). Use the universal 2-part master rule:

⚡ The Golden Allied Angle Rule

1. Function Change: If n is ODD (90°, 270°), the function changes to its co-function: sin ↔ cos, tan ↔ cot, sec ↔ cosec.
If n is EVEN (180°, 360°), the trigonometric function remains unchanged.
2. Sign Decision: The sign (+ or -) is determined strictly by the quadrant where (n × 90° ± θ) lies and the sign of the ORIGINAL function in that quadrant.

Expression Quadrant sin cos tan
90° - θ Q I +cos θ +sin θ +cot θ
90° + θ Q II +cos θ -sin θ -cot θ
180° - θ Q II +sin θ -cos θ -tan θ
180° + θ Q III -sin θ -cos θ +tan θ
270° - θ Q III -cos θ -sin θ +cot θ
270° + θ Q IV -cos θ +sin θ -cot θ
360° - θ (or -θ) Q IV -sin θ +cos θ -tan θ
MODULE 15

7-Step Identity Simplification Protocol

Entry-test identity questions require methodical reduction without getting trapped in cyclical algebra:

  1. Step 1: Start with the more complicated side (usually the side with fractions or sums).
  2. Step 2: Convert all functions into basic sine and cosine (e.g. replace tan with sin/cos, sec with 1/cos).
  3. Step 3: Combine fractions using a single common denominator.
  4. Step 4: Look immediately for Pythagorean identities in the numerator (e.g. sin² θ + cos² θ = 1, 1 - cos² θ = sin² θ).
  5. Step 5: Factor algebraic terms where possible (e.g. difference of squares, common factors).
  6. Step 6: Cancel matching binomial factors between numerator and denominator.
  7. Step 7: Reconvert to required reciprocal or quotient forms.
Worked Example 15.1 NET Exam Standard

Simplify: (1 - cos² θ) · cosec θ

1. Recognize 1 - cos² θ = sin² θ.
2. Rewrite cosec θ = 1 / sin θ.
3. Product: sin² θ · (1 / sin θ) = sin θ.
MODULE 16 & 17

Trigonometric Equations & General Solutions

Because trigonometric functions are periodic, equations have infinitely many solutions across the real number line:

Standard General Solutions (where n ∈ ℤ)
sin x = 0  ⟹  x = nπ  (or n · 180°) cos x = 0  ⟹  x = (2n + 1)π/2  (or (2n + 1) · 90°) tan x = 0  ⟹  x = nπ sin x = sin α  ⟹  x = nπ + (-1)ⁿ α cos x = cos α  ⟹  x = 2nπ ± α tan x = tan α  ⟹  x = nπ + α
Worked Example 16.1 ECAT-Style

Solve 2 cos² x - 3 cos x + 1 = 0 on the interval [0, 2π].

1. Factor quadratic: (2 cos x - 1)(cos x - 1) = 0.
2. Case A: cos x = 1/2. Positive in Q1 & Q4 → x = π/3, 5π/3.
3. Case B: cos x = 1 → x = 0, 2π.
4. Complete solution set: {0, π/3, 5π/3, 2π}.

MODULE 20 & 21

Sine Rule & Cosine Rule for Oblique Triangles

When solving triangles that do not contain a 90° right angle (oblique triangles):

The Sine Rule (Use when: AAS or SSA known)
a / sin A = b / sin B = c / sin C = 2R (where R is the circumradius of triangle ABC)
The Cosine Rule (Use when: SAS or SSS known)
c² = a² + b² - 2ab cos C  ⟺  cos C = (a² + b² - c²) / (2ab) a² = b² + c² - 2bc cos A  ⟺  cos A = (b² + c² - a²) / (2bc) b² = a² + c² - 2ac cos B  ⟺  cos B = (a² + c² - b²) / (2ac)
Worked Example 20.1 GIKI Exam Style

In triangle ABC, side a = 5, side b = 7, and the included angle C = 60°. Find side c.

1. Known configuration is SAS → Apply Cosine Rule for side c.
2. c² = 5² + 7² - 2(5)(7) cos 60° = 25 + 49 - 70(0.5) = 74 - 35 = 39.
3. c = √39 ≈ 6.24.
MODULE 22

Area of a Triangle Using Trigonometry

Trigonometric Triangle Area Formulas
Area = (1/2) ab sin C = (1/2) bc sin A = (1/2) ac sin B Hero's Formula: Area = √[s(s - a)(s - b)(s - c)]  where s = (a + b + c)/2
Worked Example 22.1 Scholarship Question

Find the area of an equilateral triangle with side length 8 cm.

1. All sides are 8 cm, all angles are 60°.
2. Area = (1/2)(8)(8) sin 60° = 32 × (√3/2) = 16√3 cm² ≈ 27.71 cm².
MODULE 23

Heights & Distances (Elevation & Depression)

Real-world modeling using the line of sight and horizontal reference line:

  • Angle of Elevation: The angle measured upward from the horizontal line of sight to the object above.
  • Angle of Depression: The angle measured downward from the horizontal line of sight to the object below. Note that by alternate interior angles, the angle of depression from top to bottom equals the angle of elevation from bottom to top!
Worked Example 23.1 IBA Aptitude Style

From the top of a 60-meter lighthouse, the angle of depression of a boat is 30°. How far is the boat from the base of the lighthouse?

1. Angle of depression = 30° ⟹ Angle of elevation at the boat = 30°.
2. tan 30° = Opposite / Adjacent = 60 / Distance.
3. 1/√3 = 60 / Distance ⟹ Distance = 60√3 meters ≈ 103.92 m.
MODULE 24 & 25

Radian Measure, Arc Length & Sector Area

A radian is the angle subtended at the center of a circle by an arc whose length equals the radius of the circle.

Universal Conversion & Circular Formulas
180° = π radians  ⟹  1° = π / 180 rad  ≈  0.01745 rad 1 radian = 180° / π  ≈  57.296° Arc Length: L = r · θ  (when θ is strictly in RADIANS) Sector Area: A = (1/2) r² θ  = (1/2) r L  (when θ in RADIANS) In Degrees: L = (θ / 360°) · 2πr,   A = (θ / 360°) · πr²
Worked Example 24.1 NET Exam Standard

Find the area of a sector of a circle of radius r = 10 cm subtended by an angle of θ = 36°.

1. Convert 36° to radians: θ = 36 × (π / 180) = π / 5 radians.
2. Sector Area = (1/2) r² θ = 0.5 × 10² × (π / 5) = 0.5 × 100 × (π / 5) = 10π cm² ≈ 31.42 cm².

• High emphasis on speed and rapid algebraic factoring.

• Fast geometric deduction over lengthy formulas.

MODULE 30

⚡ 20+ Entry-Test Speed Techniques

1. Value Substitution for Difficult Identities

If asked to simplify a complex identity with options, substitute a safe angle like θ = 45° (or 30°) into the question and match with options. Avoid angles that make denominators zero.

Example: Simplify (1 - tan² θ)/(1 + tan² θ). At θ = 45°, (1 - 1)/(1 + 1) = 0. Option cos 2(45°) = cos 90° = 0 (Matches instantly!).
2. Sec + Tan Reciprocal Pairing

If sec θ + tan θ = k, then sec θ - tan θ = 1/k immediately.

Example: sec θ + tan θ = 5 ⟹ sec θ - tan θ = 0.2. Adding gives 2 sec θ = 5.2 ⟹ sec θ = 2.6.
3. Cosec + Cot Reciprocal Pairing

If cosec θ + cot θ = p, then cosec θ - cot θ = 1/p.

Example: cosec θ + cot θ = 3 ⟹ cosec θ - cot θ = 1/3.
4. Maximum and Minimum of a sin x + b cos x

The maximum value is +√(a² + b²) and minimum value is -√(a² + b²).

Example: Max of 3 sin x + 4 cos x = √(3² + 4²) = 5. Min = -5.
5. Continuous Complementary Product: tan 1° · tan 2° · ... · tan 89°

Since tan(90° - θ) = cot θ and tan θ · cot θ = 1, all symmetric pairs cancel to 1, leaving tan 45° = 1. The whole product is 1.

6. Continuous Cosine Sum: cos 1° + cos 2° + ... + cos 179°

Since cos(180° - θ) = -cos θ, all symmetric terms cancel to 0, leaving cos 90° = 0. Total sum = 0.

7. Sum of Squares: sin² 5° + sin² 10° + ... + sin² 85°

Pair sin² θ + sin²(90° - θ) = sin² θ + cos² θ = 1. Number of pairs = 8. Add sin² 45° = 0.5. Total = 8.5.

8. Period of |sin x| and |cos x|

Taking the absolute value of standard sine or cosine folds the negative cycle into positive, halving the period from 2π to π (180°).

9. If A + B = 45°, then (1 + tan A)(1 + tan B) = 2

A standard university contest result frequently tested in FAST and NET.

10. Circumradius of a Right Triangle

The circumradius R of any right triangle is exactly half the hypotenuse: R = c / 2.

❌ 25+ Common Trigonometry Traps

⚠️ Mistake 1: Treating tan 90° as 1 or 0
❌ Wrong: tan 90° = 1
✅ Correct: tan 90° = sin 90° / cos 90° = 1 / 0 = UNDEFINED (Vertical Asymptote).
💡 Tip: Tangent is undefined at all odd multiples of 90° (±90°, ±270°).
⚠️ Mistake 2: Missing the Second Quadrant Solution in Equations
❌ Wrong: sin x = 1/2 in [0, 360°] ⟹ x = 30° only.
✅ Correct: Sine is positive in Q1 AND Q2 ⟹ x = 30° and x = 180° - 30° = 150°.
💡 Tip: Always check all quadrants where the function has the required sign.
⚠️ Mistake 3: Using Arc Formulas with Degree Angles
❌ Wrong: For r = 10, θ = 30°, writing L = 10 × 30 = 300 cm.
✅ Correct: Convert θ to radians first! θ = 30° × (π/180) = π/6 rad ⟹ L = 10 × (π/6) = 5π/3 cm.
💡 Tip: L = rθ and Area = (1/2)r²θ strictly require θ in radians.
⚠️ Mistake 4: Claiming Amplitude Can Be Negative
❌ Wrong: Amplitude of y = -4 sin x is -4.
✅ Correct: Amplitude is distance from center line and is always positive: |A| = |-4| = +4.
⚠️ Mistake 5: Measuring Reference Angle from Y-Axis
❌ Wrong: For 120°, reference angle = 120° - 90° = 30°.
✅ Correct: Reference angle is always with the X-AXIS: 180° - 120° = 60°.
