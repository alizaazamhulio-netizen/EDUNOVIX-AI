📐 Essential Formula & Constant Sheet

Intrinsic Carrier Neutrality
n = p = n_i

In intrinsic semiconductors, electron concentration strictly equals hole concentration.

Transistor Current Law
I_E = I_B + I_C

Emitter current is the sum of base current (~1-5%) and collector current (~95-99%).

Common Emitter Current Gain
β = I_C / I_B = α / (1 - α)

Typical β values range from 20 to 500 in standard bipolar junction transistors.

Common Base Current Gain
α = I_C / I_E = β / (1 + β)

Alpha is always slightly less than unity (typically 0.95 to 0.998).

LED Photon Emission
λ = h · c / E_g

Wavelength of light emitted by LED is determined by the semiconductor bandgap energy.

De Morgan's Laws
(A · B)̄ = Ā + B̄  |  (A + B)̄ = Ā · B̄

Fundamental Boolean duality rules for universal logic simplification.
