\# 🎓 EDUNOVIX-AI



> An AI-powered learning platform designed to make studying smarter, more interactive, and personalized.



EDUNOVIX-AI is a modern educational web application that combines \*\*Artificial Intelligence, interactive learning resources, student productivity tools, and progress tracking\*\* into one platform.



The goal is simple: help students \*\*learn better, practice smarter, and stay organized\*\*.

⚙️ Run Locally

1\. Clone the repository

git clone https://github.com/alizaazamhulio-netizen/EDUNOVIX-AI.git

2\. Open the project

cd EDUNOVIX-AI

3\. Install dependencies

npm install

4\. Configure environment variables



Create a .env file based on .env.example.



Example:



GEMINI\_API\_KEY=your\_api\_key\_here



Never commit your real API key to GitHub.



5\. Start the server

node server.js



The application will run locally through the configured local server.



🔐 Security



Sensitive credentials should never be committed to the repository.



This project uses environment variables for API configuration.



.env          → private

.env.example  → safe template



The .gitignore file is used to prevent sensitive and unnecessary files from being tracked.
