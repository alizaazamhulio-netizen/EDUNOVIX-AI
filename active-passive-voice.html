Fundamental Concept

1. What is Voice?

Voice tells us whether the subject of a sentence performs the action or receives the action.

Core Distinction
Active Voice: Subject performs the action.
Passive Voice: Subject receives the action.
General Illustration
Active Voice (Subject Acts) The doctor examines the patient.
➔
Passive Voice (Subject Receives) The patient is examined by the doctor.
Notice: "The doctor" does the action in active; "The patient" receives it in passive.
SubjectThe doctor
Verbexamines (V1)
Objectthe patient
TensePresent Simple

Step-by-Step: The object ("the patient") moves to the subject position. Since "the patient" is singular and the tense is Present Simple, we add "is" + V3 ("examined"), followed by "by the doctor".

Structure & Mechanics

2. Active Voice

In an active sentence, the emphasis is placed directly on the agent or doer of the action.

Basic Active Formula
Subject + Verb + Object

Clinical & Academic Examples:

  • Ali writes a letter. (Subject = Ali, Verb = writes, Object = a letter)
  • The student solves the question.
  • The teacher explains the lesson.
  • Scientists conduct experiments.
  • The nurse checks the patient.
  • The laboratory technician analyzes the sample.
Structure & Mechanics

3. Passive Voice

In a passive sentence, the emphasis shifts to the person or object that experiences or undergoes the action.

Basic Passive Formula
Object + suitable form of "be" + Past Participle (V3) + by + Subject
Transformation Walkthrough
Active The student solves the question.
➔
Passive The question is solved by the student.
Active: Student → Solves → Question | Passive: Question → is + solved → by student

Core Rule: The object of the active sentence becomes the grammatical subject of the passive sentence. The main verb "solves" must strictly change to its 3rd form (V3) "solved".

Transformation Method

4. The 5 Golden Steps ⭐

Follow these five sequential steps every time you convert an Active sentence to Passive in MDCAT:

1
Identify Elements
Find the Subject, Verb, and Object in the active sentence.
2
Relocate Object
Move the Object to the very beginning as the new subject.
3
Select "be" Form
Choose the correct auxiliary be form according to tense & new subject number.
4
Convert to V3
Change the primary main verb into its Past Participle (V3).
5
Add Agent
Append by + subject (pronoun shifted to objective case), if necessary.
5-Step Applied Example
Active The scientist performs the experiment.
➔
Passive The experiment is performed by the scientist.
Step 1: S=Scientist, V=Performs, O=Experiment | Steps 2-5 applied cleanly.
New SubjectThe experiment
Helping Verbis (singular present)
V3 Verbperformed
Agent Phraseby the scientist

Tense Rule 01

6. Present Simple

Pattern Breakdown
Active: Subject + V1/V5 + Object
Passive: Object + is/am/are + V3 (+ by Subject)
Example 01
Active The teacher teaches English.
➔
Passive English is taught by the teacher.
English is singular → uses "is" + V3 "taught"

"teaches" (V1) changes to "is taught". The subject "The teacher" becomes "by the teacher".

Example 02 (Plural Object)
Active Doctors treat patients.
➔
Passive Patients are treated by doctors.
"Patients" is plural → uses "are" + V3 "treated"

Active object "patients" is plural, so we must use "are" instead of "is".

Tense Rule 02

7. Present Continuous

Pattern Breakdown ⭐ Continuous Passive = BEING + V3
Active: Subject + is/am/are + V-ing + Object
Passive: Object + is/am/are + being + V3 (+ by Subject)
Continuous Transformation
Active The doctor is examining the patient.
➔
Passive The patient is being examined by the doctor.
Remember: Do not omit "being" in continuous tense

"is examining" transforms into "is being examined". The presence of being represents the continuous aspect.

Tense Rule 03

8. Present Perfect

Pattern Breakdown ⭐ Perfect Passive = BEEN + V3
Active: Subject + has/have + V3 + Object
Passive: Object + has/have + been + V3 (+ by Subject)
Perfect Transformation
Active The researchers have completed the experiment.
➔
Passive The experiment has been completed by the researchers.
Object "experiment" is singular → shifts from "have" to "has been"

Notice that the active sentence had plural subject "researchers" (have completed), but the new passive subject "The experiment" is singular, so it takes "has been completed".

Tense Rule 04

9. Past Simple

Pattern Breakdown
Active: Subject + V2 + Object
Passive: Object + was/were + V3 (+ by Subject)
Past Simple Transformation
Active The scientist discovered the substance.
➔
Passive The substance was discovered by the scientist.
"discovered" (V2) becomes "was discovered"

"The substance" is singular, so we use "was" + V3 "discovered".

Tense Rule 05

10. Past Continuous

Pattern Breakdown
Active: Subject + was/were + V-ing + Object
Passive: Object + was/were + being + V3 (+ by Subject)
Past Continuous Example
Active The technician was testing the machine.
➔
Passive The machine was being tested by the technician.
"was testing" becomes "was being tested"

Continuous aspect in past demands "was/were + being + V3".

Tense Rule 06

11. Past Perfect

Pattern Breakdown
Active: Subject + had + V3 + Object
Passive: Object + had + been + V3 (+ by Subject)
Past Perfect Example
Active The researchers had completed the study.
➔
Passive The study had been completed by the researchers.
"had completed" becomes "had been completed"

Both singular and plural objects take "had been + V3" in past perfect passive.

Tense Rule 07

12. Future Simple

Pattern Breakdown ⭐ Future Passive = will + be + V3
Active: Subject + will + V1 + Object
Passive: Object + will + be + V3 (+ by Subject)
Future Simple Example
Active The laboratory will conduct the test.
➔
Passive The test will be conducted by the laboratory.
"will conduct" becomes "will be conducted"

Insert "be" between "will" and the V3 verb "conducted".

Tense Rule 08

13. Future Perfect

Pattern Breakdown
Active: Subject + will have + V3 + Object
Passive: Object + will have + been + V3 (+ by Subject)
Future Perfect Example
Active The scientists will have completed the research.
➔
Passive The research will have been completed by the scientists.
"will have completed" becomes "will have been completed"

Future perfect passive incorporates "been" into the modal-perfect auxiliary chain.

Auxiliary Rules

14. Modal Verbs

Common modal auxiliaries in MDCAT English include: can, could, may, might, must, should, ought to, would, shall.

Modal Passive Formula ⭐ Modal + be + V3
Active: Subject + modal + V1 + Object
Passive: Object + modal + be + V3 (+ by Subject)
Modal "must"
Active Students must follow the instructions.
➔
Passive The instructions must be followed by students.
"must follow" becomes "must be followed"

The modal "must" stays identical; "be" is inserted, followed by V3 "followed".

Modal "can"
Active Doctors can treat the disease.
➔
Passive The disease can be treated by doctors.
"can treat" becomes "can be treated"

Do not change the modal auxiliary to past tense (do not change "can" to "could" in voice transformation).

Sentence Types

15. Negative Sentences

In negative sentences, keep "not" immediately after the first auxiliary verb. Do not alter sentence meaning or polarity.

Present Simple Negative
Active The student does not complete the assignment.
➔
Passive The assignment is not completed by the student.
"does not complete" becomes "is not completed"

"do/does not + V1" converts to "is/am/are + not + V3".

Past Simple Negative
Active The doctor did not prescribe the medicine.
➔
Passive The medicine was not prescribed by the doctor.
"did not prescribe" becomes "was not prescribed"

"did not + V1" converts to "was/were + not + V3".

Sentence Types

16. Interrogative Sentences (Questions)

Questions maintain interrogative word order in the passive voice: Auxiliary + Subject + V3?

Present Simple Question
Active Does the doctor examine the patient?
➔
Passive Is the patient examined by the doctor?
"Does ... examine?" becomes "Is ... examined?"

"Does" changes to "Is" at the beginning of the sentence to agree with singular subject "the patient".

Past Simple Question
Active Did the scientist conduct the experiment?
➔
Passive Was the experiment conducted by the scientist?
"Did ... conduct?" becomes "Was ... conducted?"

"Did" in past question converts to "Was/Were" at the front.

Commands & Requests

17. Imperative Sentences

Imperative sentences convey commands, instructions, requests, or advice.

Imperative Command Formula
Let + Object + be + V3
Command Example 01
Active Open the door.
➔
Passive Let the door be opened.
Formula: Let + door + be + opened

"Open" (V1) is transformed into "Let the door be opened".

Instruction Example 02
Active Complete the assignment.
➔
Passive Let the assignment be completed.
Formula: Let + assignment + be + completed

Alternatively in advice/requests: "You are instructed to complete the assignment."

High-Yield MDCAT Trap

18. Sentences Without an Object (Intransitives)

⚠️ Mandatory Condition for Passive Voice
A passive sentence normally requires a direct object. Intransitive verbs have no object receiving the action and CANNOT be converted to passive voice.

Exemplary Intransitive Sentences:

  • The baby sleeps. → ❌ No object. (Cannot be made passive).
  • He sleeps. → ❌ Intransitive verb.
  • They arrived early. → ❌ Intransitive verb.
  • The baby cried loudly. → ❌ Intransitive verb.
  • She laughed. → ❌ Intransitive verb.

MDCAT Trap Alert: Examiners often present options like "The baby is slept by..." which is grammatically absurd.

Stylistic & Natural English

19. When "By" Is Not Necessary

In high-level English exams, the agent ("by + subject") is omitted when the doer is: 1. Unknown, 2. Obvious, or 3. Unimportant.

Unknown Doer
Active Someone stole my bicycle.
➔
Passive My bicycle was stolen.
Natural English omits "by someone"

Saying "My bicycle was stolen by someone" is redundant because "someone" gives no meaningful information.

Universal / Obvious Agent
Active People speak English worldwide.
➔
Passive English is spoken worldwide.
"by people" is omitted

It is obvious that people speak languages, so "English is spoken worldwide" is the preferred answer in MDCAT.

Test your rapid tense identification on these classic exam traps:

Trap 1: "The patient is being examined by the doctor."
👉 Present Continuous Passive (Key: is + being + V3)
Trap 2: "The experiment has been completed."
👉 Present Perfect Passive (Key: has + been + V3)
Trap 3: "The sample was analyzed by the technician."
👉 Past Simple Passive (Key: was + V3)
Trap 4: "The test will be conducted tomorrow."
👉 Future Simple Passive (Key: will + be + V3)

👉 Modal Passive (Key: must + be + V3)
Error Analysis

24. Common Mistakes (8+ Warning Cards)

Review these frequent grammatical pitfalls that cause students to lose marks in MDCAT:

❌ The letter is wrote by Ali.
✅ The letter is written by Ali.
Why: "wrote" is V2. Passive voice strictly requires V3 (written).
❌ The patient is being examine.
✅ The patient is being examined.
Why: Main verb must be V3 ("examined"), not base form ("examine").
❌ The experiment has been complete.
✅ The experiment has been completed.
Why: After "has been", the verb must be past participle ("completed").
❌ The work will be done by him yesterday.
✅ The work was done by him yesterday.
Why: Tense mismatch! Time adverbial "yesterday" demands Past Simple ("was done").
❌ The baby is slept by the mother.
✅ The baby sleeps peacefully. (No passive possible)
Why: "sleep" is intransitive; it has no direct object to convert.
❌ The medicine was not prescribe.
✅ The medicine was not prescribed.
Why: Negative passive still uses V3 ("prescribed").
❌ The instructions must been followed.
✅ The instructions must be followed.
Why: Modal verbs take "modal + be + V3", not "been".
❌ Who was wrote this article?
✅ By whom was this article written?
Why: "Who" transforms to "By whom + auxiliary + subject + V3".
