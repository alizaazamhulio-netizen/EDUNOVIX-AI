Introduction to Exponents

📖 What is an Exponent?

An exponent (also known as a power or index) is a shorthand mathematical operation indicating how many times a number (the base) is multiplied by itself.

aⁿ = a × a × a × ... × a    (n times)

In plain English:
• Exponent asks: "What is the result when I multiply the base a by itself n times?"
• Example: 2⁴ = 2 × 2 × 2 × 2 = 16.

⚡ Fundamental Concept Check

Exponents turn repeated multiplication into concise algebra. When you see 3⁵, you immediately think: five threes multiplied together = 243.

02 & 03

Base and Exponent (Positive Powers & Brackets)

In the expression aⁿ:
• a is the Base (the factor being multiplied).
• n is the Exponent (the count of multiplications).

⚠️ The Critical Brackets Trap in Entry Tests

One of the most frequent point-loss mistakes in FAST, NET, and ECAT tests is confusing:
Case 1: (-2)² = (-2) × (-2) = +4 (The bracket includes the negative sign in the squaring).
Case 2: -2² = -(2 × 2) = -4 (Order of operations: exponent applies ONLY to 2, then negated).

Zero and Negative Exponents

Rule 1: Zero Exponent Law
a⁰ = 1    (for any a ≠ 0)

Why? By quotient law, aⁿ / aⁿ = aⁿ⁻ⁿ = a⁰. But any non-zero quantity divided by itself is 1. Hence a⁰ = 1.

Note: 0⁰ is indeterminate.

Rule 2: Negative Exponent Law
a⁻ⁿ = 1 / aⁿ    (for a ≠ 0)

A negative exponent indicates a reciprocal. It does not make the number negative!

(a / b)⁻ⁿ = (b / a)ⁿ

Fractional & Rational Exponents

🔗 Connecting Powers and Roots

A fractional exponent seamlessly binds roots and powers into algebraic arithmetic:

a^(m/n) = ⁿ√(aᵐ) = (ⁿ√a)ᵐ

• Denominator (n): Controls the Root Index (e.g. 2 is square root, 3 is cube root).
• Numerator (m): Controls the Power.

💡 Entry-Test Speed Strategy for Rational Powers

Always take the root first before taking the power!
Example: To calculate 27^(2/3):
• Slower way: √(27²) = √729 = 9 (hard without calculator).
• Speed way: (³√27)² = (3)² = 9 (takes 2 seconds mentally!).

Scientific Notation

Standard Form Definition
a × 10ⁿ    where   1 ≤ a < 10,   n ∈ ℤ

• Moving decimal to the left increases n (large numbers: 3000 = 3 × 10³).
• Moving decimal to the right decreases n (small decimals: 0.0045 = 4.5 × 10⁻³).

Exponential Growth & Decay

📈 Exponential Growth Model
y = a(1 + r)ᵗ

• a: Initial amount (at t = 0).
• r: Growth rate per period (as a decimal).
• 1 + r: Growth factor (> 1).
• t: Elapsed time units.

📉 Exponential Decay Model
y = a(1 - r)ᵗ

• a: Initial amount.
• r: Decay / depreciation rate.
• 1 - r: Decay factor (0 < factor < 1).
• t: Elapsed time units.

Introduction to Logarithms & The Fundamental Relationship

📖 What is a Logarithm?

A logarithm is the exact mathematical inverse of an exponent.

aˣ = b    ⟺    logₐ(b) = x

• Exponent asks: "What is the result when base a is raised to power x?"
• Logarithm asks: "What power x must base a be raised to in order to produce b?"

🔄 Exponential ↔ Logarithmic Live Converter

Exponential Form: aˣ = b

Logarithmic Form: logₐ(b) = x

17 - 20

Logarithm Conditions, Common / Natural Bases & Key Values

⚠️ Mandatory Domain Conditions for logₐ(x) in ℝ

1. Argument must be strictly positive: x > 0 (Log of zero or negative numbers is undefined in ℝ).
2. Base must be strictly positive: a > 0.
3. Base cannot be 1: a ≠ 1 (since 1ˣ = 1 always, which has no unique inverse).

Common Logarithm (Base 10)

Written simply as log(x) without a base index.

• log(10) = 1
• log(100) = 2
• log(1000) = 3
• log(0.1) = -1

Natural Logarithm (Base e)

Written as ln(x) = logₑ(x), where Euler's number e ≈ 2.71828.

• ln(1) = 0
• ln(e) = 1
• ln(eˣ) = x
• e^(ln x) = x

Laws of Logarithms & Change of Base

1. Product Rule
logₐ(xy) = logₐ(x) + logₐ(y)

Multiplication inside becomes addition outside.

2. Quotient Rule
logₐ(x/y) = logₐ(x) - logₐ(y)

Division inside becomes subtraction outside.

3. Power Rule
logₐ(xⁿ) = n · logₐ(x)

Power comes down as a multiplying coefficient.

4. Change of Base
logₐ(b) = log(b) / log(a) = ln(b) / ln(a)

Allows evaluation in any arbitrary base.

Solving Exponential & Logarithmic Equations (Extraneous Root Detection)

Type 1: Same Bases Equated
aᶠ⁽ˣ⁾ = aᵍ⁽ˣ⁾   ⟹   f(x) = g(x)

Example: 2ˣ⁺¹ = 16 ⟹ 2ˣ⁺¹ = 2⁴ ⟹ x + 1 = 4 ⟹ x = 3.

Type 2: Quadratic Substitution
A(aˣ)² + B(aˣ) + C = 0

Let u = aˣ (where u > 0), solve for u, then back-substitute.

Type 3: Taking Logs for Unequal Bases
3ˣ = 20   ⟹   x = log(20) / log(3)

Apply natural or common log to both sides and bring powers down.

⚠️ Extraneous Solutions Warning in Log Equations

When solving logarithmic equations, algebraic manipulations (like using log x + log y = log(xy)) can introduce fake (extraneous) solutions that make an original argument negative!
Golden Rule: Always substitute every solved x back into EVERY original logarithm argument. If any argument becomes ≤ 0, discard it immediately.

⚠️ 30 Common Entry-Test Mistakes & Fixes

❌ Mistake 1: Splitting log of sum

Wrong: log(x + y) = log x + log y

✅ Correct: log(xy) = log x + log y. log(x + y) cannot be simplified.

❌ Mistake 2: Splitting log of difference

Wrong: log(x - y) = log x - log y

✅ Correct: log(x / y) = log x - log y.

❌ Mistake 3: Confusing log quotient with division

Wrong: log(x/y) = (log x) / (log y)

✅ Correct: log(x/y) = log x - log y.

❌ Mistake 4: Power of log vs log of power

Wrong: (log x)² = 2 log x

✅ Correct: log(x²) = 2 log x. (log x)² means (log x) × (log x).

❌ Mistake 5: -aⁿ vs (-a)ⁿ

Wrong: Thinking -3² = 9

✅ Correct: -3² = -9. Only (-3)² = +9.

❌ Mistake 6: Forgetting Extraneous Roots

Wrong: Accepting x = -2 as solution to log(x) + log(x-3) = 1.

✅ Correct: Discard x = -2 because log(-2) is undefined in ℝ.

10-Minute Rapid Revision Summary

1. Exponent Laws In a Flash

• Multiply same bases ⟹ Add powers: aᵐ aⁿ = aᵐ⁺ⁿ.

• Divide same bases ⟹ Subtract powers: aᵐ/aⁿ = aᵐ⁻ⁿ.

• Power of power ⟹ Multiply: (aᵐ)ⁿ = aᵐⁿ.

• Negative power ⟹ Reciprocal: a⁻ⁿ = 1/aⁿ.

• Fractional power ⟹ Root & Power: a^(m/n) = ⁿ√(aᵐ).

2. Logarithm Laws In a Flash

• Definition: aᶜ = b ⟺ logₐ b = c (Base stays base!).

• Product: log(xy) = log x + log y.

• Quotient: log(x/y) = log x - log y.

• Power: log(xⁿ) = n log x.

• Base change: logₐ b = ln b / ln a.

3. Domain Rules & Traps

• For logₐ(x): Base a > 0, a ≠ 1. Argument x > 0.

• Zero or negative arguments are strictly undefined in ℝ.

• Always test solved roots for extraneous values.

4. Functions & Graphs

• y = aˣ has horizontal asymptote y = 0, passes through (0, 1).

• y = logₐ x has vertical asymptote x = 0, passes through (1, 0).

• y = aˣ and y = logₐ x reflect across the identity line y = x.
