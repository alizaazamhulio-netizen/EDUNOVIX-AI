1. What is a Quadratic Equation?

A quadratic equation is a second-degree polynomial equation in a single variable where the highest exponent of the variable is exactly 2.

General Standard Form
ax² + bx + c = 0     (where a ≠ 0, and a, b, c ∈ ℝ)
📌 What a, b, and c Represent

• a is the quadratic coefficient (multiplier of x²).
• b is the linear coefficient (multiplier of x).
• c is the constant term (independent of x).

⚠️ Why a Cannot Be Zero (a ≠ 0)

If a = 0, the leading term 0·x² vanishes. The equation degrades into bx + c = 0, which is a first-degree linear equation, losing all quadratic properties.

🎯 Linear vs Quadratic

A linear equation (degree 1) has at most 1 root and graphs as a straight line. A quadratic equation (degree 2) has exactly 2 roots (real or complex) and graphs as a smooth U-shaped curve called a parabola.

⚡ FAST Exam Diagnostic Check
In FAST entry tests, you are often given disguised algebraic expressions. You must always simplify and expand before deciding if an equation is quadratic!

Interactive Check: Is it Quadratic or Not? (8 Examples)

Verdict: ✅ YES, it is Quadratic.
Degree is 2, a = 3 (≠ 0), b = -5, c = 7. Standard form satisfied.
2. (x + 2)² = 2(x - 3)
Verdict: ✅ YES, it is Quadratic.

4. x + 1/x = 4 (for x ≠ 0)
Verdict: ✅ YES, it is Quadratic.
Multiplying entire equation by x: x² + 1 = 4x ⇒ x² - 4x + 1 = 0.
5. x³ - 4x² - x + 1 = (x - 2)³
Verdict: ✅ YES, it is Quadratic.
RHS = x³ - 6x² + 12x - 8. The x³ terms cancel out: 2x² - 13x + 9 = 0.
6. 2x² - √x + 3 = 0
Verdict: ❌ NO, not a Polynomial.
The term √x has exponent 1/2. Polynomial equations require whole number exponents.

Verdict: ✅ YES, Pure Quadratic.
a = 5, b = 0, c = 0. Both roots are equal to 0.
8. (x² + 1)² = x⁴ + 3x + 2
Verdict: ✅ YES, it is Quadratic.
LHS = x⁴ + 2x² + 1. The x⁴ terms cancel: 2x² - 3x - 1 = 0.

2. Standard Form: ax² + bx + c = 0

Any quadratic equation must always be arranged in descending order of powers equal to zero before applying any method (Factorization, Completing the Square, or Quadratic Formula).

Standard Form Transformation Algorithm Essential Rule
1
Clear Fractions & Parentheses
Multiply by common denominators and expand all binomial expansions like (x+p)(x+q) or (ax+b)².
2
Shift All Terms to One Side
Collect all quadratic, linear, and constant terms on one side leaving 0 on the other side.
3
Combine Like Terms & Ensure a > 0
Simplify terms. It is conventional and prevents sign mistakes to keep leading coefficient 'a' positive.
📝 Worked Example: Rearranging Disordered Form
Given: 4 - 3x + x² = 0
Rearranging in descending power order: x² - 3x + 4 = 0 (a = 1, b = -3, c = 4).

3. Identifying a, b, and c & Sign Discipline

Identifying a, b, and c correctly is the single most critical foundation. Over 40% of student errors in entry tests arise simply from dropping negative signs or misidentifying zero coefficients.

➕ / ➖ Rule 1: The Sign Travels with the Term

In 3x² - 7x - 5 = 0:
• a = +3
• b = -7 (not +7)
• c = -5 (not +5)

0️⃣ Rule 2: Missing Terms Have Coefficient 0

In 4x² - 9 = 0, there is no linear x term. Thus b = 0.
In 2x² + 5x = 0, there is no constant term. Thus c = 0.

1️⃣ Rule 3: Invisible Coefficient is 1

In x² - x + 6 = 0:
• The coefficient of x² is 1 (not 0).
• The coefficient of x is -1.

4. Roots, Solutions, and Zeroes

A root (or solution) of a quadratic equation is a specific numerical value of x that makes the equation true (i.e. evaluates LHS = 0).

🔑 The Three Synonyms

• Root: Value of x satisfying the algebraic equation ax² + bx + c = 0.
• Solution: Member of the truth set of the equation.
• Zero: x-value where polynomial function P(x) = 0 (the x-intercept on the graph).

🧪 The Substitution Verification Test

For x² - 5x + 6 = 0:
• Test x = 2: (2)² - 5(2) + 6 = 4 - 10 + 6 = 0 (Verified!)
• Test x = 3: (3)² - 5(3) + 6 = 9 - 15 + 6 = 0 (Verified!)
Hence, 2 and 3 are the roots.

5. Solving by Simple Factorization (x² + bx + c = 0)

When the leading coefficient a = 1, solving by factorization relies on finding two numbers p and q such that:

Product-Sum Rule
p + q = b     \text{and}     p \cdot q = c
\Rightarrow (x + p)(x + q) = 0 \Rightarrow x = -p  \text{or}  x = -q
⚖️ The Zero-Product Property
If A · B = 0, then either A = 0, or B = 0, or both. This fundamental algebraic property allows us to split a single quadratic into two linear equations!

6. Advanced Factorization (ax² + bx + c = 0)

When a ≠ 1, we use the Splitting the Middle Term Method (ac-method).

Middle Term Splitting Protocol: 2x² + 7x + 3 = 0 Full Working
1
Calculate Product P = a · c
P = 2 · 3 = 6. Sum required S = b = 7.
2
Find Factors of 6 that add to 7
The two numbers are 6 and 1 (6 × 1 = 6, 6 + 1 = 7).
3
Split the Middle Term & Group
2x² + 6x + 1x + 3 = 0 ⇒ 2x(x + 3) + 1(x + 3) = 0.
4
Factor Common Binomial
(2x + 1)(x + 3) = 0 ⇒ x = -1/2 or x = -3.

7. Completing the Square Method

Completing the square transforms any quadratic expression into the form (x + d)² = k, enabling direct extraction of square roots. This method is also used to derive the Quadratic Formula!

The Magic Term to Add
x² + bx + \left(\frac{b}{2}\right)^2 = \left(x + \frac{b}{2}\right)^2
Worked Example: x² + 6x + 5 = 0 Step-by-Step
1
Move Constant Term to RHS
x² + 6x = -5
2
Compute (b/2)² and Add to BOTH Sides
b = 6 ⇒ (6/2)² = 3² = 9. Adding 9: x² + 6x + 9 = -5 + 9 ⇒ (x + 3)² = 4.
3
Take Square Roots of Both Sides
x + 3 = ±√4 ⇒ x + 3 = ±2.
4
Solve for Both Roots
x = -3 + 2 = -1 or x = -3 - 2 = -5.
⚠️ Common Trap when Leading Coefficient a ≠ 1
You MUST divide the entire equation by 'a' BEFORE calculating (b/2)². For example in 2x² + 8x - 10 = 0, first divide by 2 to get x² + 4x - 5 = 0, then add (4/2)² = 4.
Topic 08 / 18 Core Formula

8. The Quadratic Formula (⭐ Must Know)

The Quadratic Formula is the universal tool that solves EVERY quadratic equation, whether factorable or non-factorable, rational or irrational, real or complex.

⭐ THE QUADRATIC FORMULA ⭐
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
Full Worked Example: 2x² + 5x - 3 = 0 5-Step Master Guide
1
Identify Coefficients with Signs
a = 2, b = 5, c = -3.
2
Calculate Discriminant D = b² - 4ac
D = (5)² - 4(2)(-3) = 25 - (-24) = 25 + 24 = 49.
3
Substitute into Formula
x = (-5 ± √49) / [2(2)] = (-5 ± 7) / 4.
4
Separate the ± and Simplify
Root 1: x = (-5 + 7)/4 = 2/4 = 1/2.
Root 2: x = (-5 - 7)/4 = -12/4 = -3.
Topic 09 / 18 Core Formula

9. Discriminant (D = b² - 4ac)

The quantity under the square root in the quadratic formula, D = b² - 4ac, is called the discriminant because it "discriminates" (distinguishes) between the different types of roots without needing to solve the full equation.

● Case 1: D > 0 (Positive)

• Two distinct real roots.
• If D is a perfect square (e.g. 1, 4, 9, 25, 49), roots are Rational.
• If D is NOT a perfect square (e.g. 2, 3, 5, 8), roots are Irrational conjugate surds (p ± √q).

● Case 2: D = 0 (Zero)

• Two equal real roots (repeated / double root).
• Roots are real, rational, and both equal to x = -b / (2a).
• The parabola touches the x-axis at exactly 1 vertex point.

● Case 3: D < 0 (Negative)

• No real roots.
• The roots are two complex conjugate imaginary roots (u ± vi).
• The parabola does not intersect the x-axis at all.

11. Sum and Product of Roots (Vieta's Relations)

For any quadratic equation ax² + bx + c = 0 with roots α (alpha) and β (beta):

\alpha + \beta = -\frac{b}{a}        \alpha\beta = \frac{c}{a}
🌟 Symmetric Expressions (High-Yield FAST Tricks)

• α² + β²: (α + β)² - 2αβ = (-b/a)² - 2(c/a) = (b² - 2ac) / a²
• 1/α + 1/β: (α + β) / (αβ) = (-b/a) / (c/a) = -b / c
• |α - β|: √[(α + β)² - 4αβ] = √(D) / |a|
• α³ + β³: (α + β)³ - 3αβ(α + β)

⚡ Entry Test Speed Example

Given: 2x² - 7x + 3 = 0
• Sum of roots: α + β = -(-7)/2 = 7/2
• Product of roots: αβ = 3/2
• Value of 1/α + 1/β = (7/2) / (3/2) = 7/3 (Solved in 4 seconds without finding α and β!)

12. Forming a Quadratic Equation from Given Roots

If α and β are the roots of a quadratic equation, let S = α + β (Sum) and P = αβ (Product). The equation is given by:

x^2 - S x + P = 0   \Rightarrow   x^2 - (\alpha + \beta)x + \alpha\beta = 0

Topic 13 / 18 Application

13. Real-World Word Problems (12 Solved Models)

Word problems test your ability to translate verbal scenarios into algebraic models. Always follow the 5-step blueprint:

1. Area & Rectangle Problem

Problem: A rectangular garden has length 4m greater than its width. If area is 96 m², find width.
Model: w(w + 4) = 96 ⇒ w² + 4w - 96 = 0 ⇒ (w + 12)(w - 8) = 0.
Result: Reject negative dimension -12. Width = 8 m, Length = 12 m.

2. Consecutive Positive Integers

Problem: Product of two consecutive positive integers is 156. Find the numbers.
Model: n(n + 1) = 156 ⇒ n² + n - 156 = 0 ⇒ (n + 13)(n - 12) = 0.
Result: Since n > 0, n = 12, so integers are 12 and 13.

3. Right Triangle Hypotenuse

Problem: Hypotenuse is 13 cm. One leg is 7 cm longer than the other.
Model: x² + (x + 7)² = 13² ⇒ 2x² + 14x - 120 = 0 ⇒ x² + 7x - 60 = 0 ⇒ (x + 12)(x - 5) = 0.
Result: Shorter leg = 5 cm, longer leg = 12 cm.

4. Speed, Distance & Time

Problem: Train travels 132 km. Express train is 11 km/h faster and takes 1 hr less.
Model: 132/v - 132/(v+11) = 1 ⇒ v² + 11v - 1452 = 0 ⇒ (v + 44)(v - 33) = 0.
Result: Passenger speed = 33 km/h, Express = 44 km/h.

5. Number & Reciprocal Sum

Problem: Sum of a number and its reciprocal is 10/3.
Model: x + 1/x = 10/3 ⇒ 3x² - 10x + 3 = 0 ⇒ (3x - 1)(x - 3) = 0.
Result: The number is 3 or 1/3.

6. Pipes and Cisterns

Problem: Two pipes fill a tank in 100/9 min. One takes 5 min more than the other.
Model: 1/t + 1/(t+5) = 9/100 ⇒ 9t² - 155t - 500 = 0 ⇒ (t - 20)(9t + 25) = 0.
Result: Faster pipe takes 20 minutes.

14. 🚀 FAST & Scholarship Speed Shortcuts

Entry tests like FAST give you ~50 seconds per question. Use these 8 elite mathematical shortcuts to solve questions in under 10 seconds without standard expansion:

⚡ Shortcut 1: a + b + c = 0

If the sum of all coefficients equals zero, x = 1 is ALWAYS a root, and the second root is c / a.
Example: 17x² - 25x + 8 = 0 (17 - 25 + 8 = 0) ⇒ Roots are 1 and 8/17 immediately!

⚡ Shortcut 2: a - b + c = 0

If alternating sum is zero, x = -1 is ALWAYS a root, and the second root is -c / a.
Example: 7x² + 11x + 4 = 0 (7 - 11 + 4 = 0) ⇒ Roots are -1 and -4/7!

⚡ Shortcut 3: Reciprocal Roots Condition

If the roots are reciprocal to each other (α and 1/α), then product = 1 ⇒ c = a.
FAST Tip: If a = c, roots are automatically multiplicative inverses!

⚡ Shortcut 4: Equal Magnitude Opposite Sign

If roots are α and -α (additive inverses), then sum = 0 ⇒ b = 0.
Equation simplifies to ax² + c = 0.

⚡ Shortcut 5: Options Elimination by Product

Check the product of roots c/a against the product of option pairs. 75% of distractors fail the constant term sign test instantly.

⚡ Shortcut 6: Ratio of Roots r : 1

If roots are in ratio r : 1, use the master relation: r b² = ac (r + 1)².

15. 15 Common Mistakes to Avoid

Analyze these 15 frequent pitfalls that cost students valuable negative marking points:

1. Negative Sign in -b Formula
❌ In x² - 6x + 8 = 0, using -b = -6
✅ -b = -(-6) = +6
💡 The formula has a built-in negative sign that flips the sign of b.
2. Squaring Negative Coefficients
❌ Calculating (-5)² as -25 in discriminant
✅ (-5)² = +25 always
💡 Any real number squared is non-negative.
3. Forgetting ± in Square Root
❌ x² = 25 ⇒ x = 5 only
✅ x = ±5 (two roots: +5 and -5)
💡 A quadratic equation must have two solutions.
4. Dividing by Variable x
❌ Solving x² = 5x by dividing by x to get x = 5
✅ x² - 5x = 0 ⇒ x(x - 5) = 0 ⇒ x = 0 or 5
💡 Dividing by x eliminates the valid root x = 0.
5. Forgetting 2a in Denominator
❌ Dividing only the square root by 2a: -b ± √(D)/2a
✅ Entire numerator (-b ± √D) is divided by (2a)
💡 Fraction bar extends under both -b and the radical.
6. Non-zero Right Hand Side Factorization
❌ (x - 2)(x - 3) = 12 ⇒ x - 2 = 12 or x - 3 = 12
✅ Expand: x² - 5x + 6 = 12 ⇒ x² - 5x - 6 = 0 ⇒ (x - 6)(x + 1) = 0
💡 Zero-Product property only works when RHS is 0.
